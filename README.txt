TSHEPISO TESHANE — PORTFOLIO WEBSITE

Files:
- index.html: website content
- style.css: visual design and responsive layout
- script.js: mobile navigation and current year

BEFORE PUBLISHING:
1. Replace YOUR_EMAIL@example.com with your professional email.
2. Replace YOUR PHONE NUMBER with the mobile number you want to publish.
3. Replace YOUR_LINKEDIN_URL and YOUR_GITHUB_URL with real links, or remove the rows if you do not want to share them.
4. Check the availability hours and change them to your real schedule.
5. Confirm the rate card matches the services you can confidently deliver.
6. Add real links/screenshots for your projects when available.
7. Open index.html in a browser to preview the site.

The site is a static HTML/CSS/JavaScript portfolio. It can be hosted on a static hosting service such as Cloudflare Pages. The email button uses a mailto link rather than a server-backed contact form.
